🚀 DualBoot Git SyncA safe, deterministic, one-click Git synchronization utility designed for dual-boot developers.This tool standardizes your workflow across Linux, Windows, and macOS, preventing the "forgot-to-pull" headache and keeping your cross-platform development environment in perfect sync.🎯 The ProblemDual-booting is great, but Git synchronization is often messy:Sync Amnesia: Forgetting to pull before starting work on a different OS.Merge Hell: Conflicts caused by unsynced edits across partitions.NTFS Noise: File permission "flapping" when switching between Linux and Windows.✅ The SolutionDualBoot Git Sync enforces a strict Rebase-First strategy through a simple one-click command:Pull & Rebase: Fetches the latest remote changes and applies your work on top.Stage All: Automatically stages new files and deletions.Atomic Commit: Commits only if changes exist (prevents empty commits).Push: Syncs your local state back to the cloud.🧠 Design PhilosophyWhat it is NOTWhat it IS❌ No hidden background services✅ Manual, intentional synchronization❌ No silent "ghost" commits✅ Explicit rebase-first workflow❌ No automatic push on shutdown✅ Cross-platform parity & visibility📂 Project Structuredualboot-git-sync/
